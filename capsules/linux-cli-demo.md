# Linux CLI Essentials

Learn the most important Linux commands every developer should know.

---

## Why Learn the Terminal?

The Linux terminal is one of the most powerful tools available to developers.

It allows you to automate tasks, manage servers, and work efficiently.

---

## Basic Commands

- pwd
- ls
- cd
- mkdir
- rm
- cp
- mv

---

## Creating Directories

```bash
mkdir my_project
cd my_project
touch main.py
```

---

## Listing Files

```bash
ls -la
```

---

## Useful Shortcuts

| Shortcut | Description |
|----------|-------------|
| Ctrl + C | Stop current command |
| Ctrl + L | Clear screen |
| Ctrl + D | Logout terminal |
